# Ground rules

Local-only notes for this repo. Gitignored, never committed, never pushed.

## 1. Stay inside this repo

Do not read, list, search, or run anything outside
`/Users/zsl/Documents/synergy-website`. That includes the home directory, other
projects, and system paths. If a task looks like it needs something from
outside, stop and ask for permission first. Going outside without that
permission is a hard stop, not a judgment call.

## 2. No AI-sounding writing anywhere in this repo

This covers every word that ends up in the repo: site copy, research area
descriptions, bios, code comments, commit messages, README text.

Do not use:

- Em dashes as a dramatic pause.
- "Not just X, it's Y" and "X isn't about Y, it's about Z".
- Rule-of-three lists where two items would say the same thing.
- Filler adverbs: actually, truly, simply, seamlessly, genuinely, robustly.
- Inflated verbs and nouns: leverage, unlock, empower, surface (as a verb),
  at scale, deep dive, journey, landscape.
- A sentence that restates the sentence before it in different words.
- A closing sentence that tells the reader what they just read.

Write plain declarative sentences. Name the specific thing. If a sentence could
appear on any other lab's website without changing a word, cut it.
